Now Playing for Windows

1. Open Now-Playing-Windows-Setup.exe and install.
2. Open Now Playing from your Start menu.
3. Allow microphone access if Windows asks, then play music nearby.

The display opens in your browser. The first model startup can take a minute.
You do not need Python, a terminal, Spotify, or an API key.
Use the app's Microphone selector if it chooses the wrong input.
Close the Now Playing control window to stop listening.
Internet access is needed to identify songs and download new covers.

Album history is kept in your Windows user profile and survives upgrades.
App logs: %LOCALAPPDATA%\NowPlaying\listener.log

This preview installer is unsigned, so Windows may show a publisher warning.
Only install a build obtained from the project's GitHub release page.
https://github.com/Jack-Rouleau/vinyl-now-playing/releases
